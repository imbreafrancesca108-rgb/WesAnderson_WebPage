# Wes Anderson Cinematography Website 🎬

> A web application dedicated to the unique visual style, aesthetics, and masterpieces of acclaimed film director Wes Anderson.

---

##  Project Description

This project is a multi-page web application that explores the signature cinematic style of **Wes Anderson**, featuring iconic elements such as symmetrical composition, planimetric framing, and distinct pastel color palettes. 

The website includes dedicated pages for several of his renowned films (such as *The Grand Budapest Hotel*, *Isle of Dogs*, *Asteroid City*, and *Fantastic Mr. Fox*), complete with trailers, plots, cast details, awards, and an interactive feedback system with local storage and keyboard shortcuts.

---

##  Key Features

* **Interactive Menu & Multi-page Navigation:** Easily switch between the main page and individual movie pages (e.g., *The Grand Budapest Hotel*).
* **Multimedia Support:** Embedded video trailers and responsive image galleries.
* **Interactive Feedback Form:** Hidden by default (toggled via keyboard shortcut `F`), featuring client-side validation, range sliders, and data handling with `localStorage` and AJAX (`fetch`).
* **Dynamic JavaScript Enhancements:**
  * Keyboard listeners (`P` for popup alerts, `F` for toggling the feedback form).
  * Timed background color changes for the footer.
  * Local storage history tracking for page visits.

---

##  Tech Stack

* **Markup:** HTML5 (semantic elements, semantic forms)
* **Styling:** CSS3 (Flexbox/Grid, custom layouts, responsive design)
* **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, Async/Await, Fetch API, LocalStorage)
